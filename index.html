Product Development Roadmap

From Heuristics to Agents: Validation Strategy

Don't build real-time AI agents first. Build incrementally and validate unit economics at each stage.

Phase 1: Rule-Based Heuristics
Week 1 launch • Latency: <100ms
LAUNCH HERE
Simple rules that handle 90% of decisions:
// Auto-approve
if (overLimit < 5% && utilization < 70% && paymentHistory === 100%)
→ approve instantly
// Auto-decline
if (overLimit > 10% || utilization > 90% || latePayments > 0)
→ decline instantly
// Manual review
else → queue for ops team review (SLA: 2 hours)
📊 Validation Milestone (Week 4)
• Measure: Do auto-approved transactions default at <2%?
• Measure: Does manual review queue stay <10% of volume?
• If yes → proceed to Phase 2. If no → tune thresholds.
Phase 2: ML Model for Edge Cases
Month 3 • Latency: <500ms
Model handles the 10% that need nuanced decisions:
Model Inputs
• Utilization trend (not just point)
• Payment velocity (avg days early)
• Merchant risk score
• Transaction predictability
• Business growth signals
Model Output
• PD estimate (1.8% vs 5%)
• Confidence score
• If confidence < 80% → manual review
• If confidence > 80% → auto decision
📊 Validation Milestone (Month 6)
• A/B test: Model vs heuristics on edge cases
• Measure: Does model reduce false declines by >20%?
• Measure: Does model maintain <2% default rate?
• If yes → proceed to Phase 3. If no → improve features.
Phase 3: Agent for Complex Scenarios
Month 9-12 • Latency: 30 sec - 5 min (async)
Agent handles <5% of transactions that need creativity:
Agent triggered when:
• Transaction declined BUT customer has good history
• Model uncertainty high (confidence 50-80%)
• Customer value is high (LTV > $100k)

Agent responsibilities:
• Generate approval options (early pay, add account, etc)
• Estimate benefit of each option ($765 cashback vs $0)
• Create Slack channel to coordinate stakeholders
• NOT real-time - async workflow is fine here
⚠️ Latency Reality Check
• Don't block transaction on agent (~5 min to generate options)
• Instead: Decline immediately, send notification
• Agent runs async, presents options in Slack
• User re-attempts transaction after option selected
• This is fine! Users understand "needs approval" flow.
📊 Validation Milestone (Month 12)
• Measure: Do agent-suggested options convert? (target >60%)
• Measure: Does agent-touched cohort have better LTV? (vs declined)
• Measure: Does agent reduce ops manual review time?
• Calculate: ROI of agent vs cost of running (LLM inference + eng time)
✓ Smart Product Strategy: Validate Economics at Each Stage
Volume distribution after Phase 3:
• 85% auto-approved by heuristics (<100ms)
• 8% approved/declined by model (<500ms)
• 5% handled by agent (30s-5min async)
• 2% manual review by ops

Key insight: Agent is the smallest piece, not the foundation. Build the boring stuff first, add intelligence where it actually matters.
